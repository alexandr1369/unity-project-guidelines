# Работа с репозиторием правил

Это репозиторий плагина `unity-project-guidelines` для Claude Code и Codex, а не Unity-проект.
Перед изменениями читай `skills/unity-project-guidelines/SKILL.md` и профильные документы
по теме. Правила оформления коммитов из раздела «Правила коммитов» в `GIT_WORKFLOW.md`
действуют и здесь.

Общие правила изменяй в профильных документах, не копируя их в этот файл. Порядок
веток и PR для Unity-проектов здесь не применяется: по решению владельца изменения
репозитория правил коммитятся и отправляются прямо в `main`, без PR.

После каждого push в `main` обнови установленный плагин у Claude Code и Codex командами
из раздела «Обновление» `README.md`: агенты читают установленную копию, а не этот клон.

`AGENTS.md` и `CLAUDE.md` поддерживай побайтово одинаковыми.
